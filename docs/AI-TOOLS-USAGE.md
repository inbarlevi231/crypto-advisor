# AI Tools Usage Summary

I started by planning and defining the project requirements: I spent the first half-day going through the assignment thoroughly, researching the crypto domain and relevant APIs (CoinGecko, MarketAux, OpenRouter), and deciding how the interface and user flow should work (auth → onboarding → personalized dashboard → feedback). I used Cursor to help evaluate the stack (React/Vite, Node/Express, MongoDB) and then to implement the project—backend first, then frontend—while I directed the product decisions, reviewed suggestions, and tested critical paths myself. Finally I focused on refining UX, fixing production issues (API fallbacks, deploy/env config, dashboard layout), and closing any functionality gaps before submission. I treated Cursor as a pair-programming assistant rather than a replacement for ownership of the design and results.
